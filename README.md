🚀 Algoritmos y Programación II — Proyectos & Desafíos

Repositorio dedicado al aprendizaje, la experimentación y la aplicación práctica de herramientas, frameworks y lenguajes de programación, mediante el desarrollo de las actividades académicas y desafíos asignados en la materia **Algoritmos y Programación II**.

💡 Nota personal: Como desarrollador en constante formación, este espacio representa mis primeros pasos explorando el ecosistema de JavaScript, React y el desarrollo web moderno, aplicando conceptos fundamentales de Estructuras de Datos y Algoritmos en proyectos reales e interactivos.

🛠️ Tecnologías, Frameworks y Lenguajes Utilizados:

JavaScript (ES6+): Lenguaje principal de programación utilizado para implementar desde cero la lógica de las estructuras de datos (Listas Enlazadas, Pilas, Colas, Árboles BST, Árboles N-arios y Grafos).
React: Framework / librería cliente utilizada para construir interfaces de usuario interactivas, reactivas y componentes reutilizables para cada uno de los proyectos.
Vite: Entorno de desarrollo y empaquetador ultrarrápido utilizado para la creación y estructuración de los proyectos en React.
HTML5 & CSS3: Estilizado personalizado empleando desde variables CSS globales hasta temas visuales complejos (Dark Mode, Fintech Neo-Brutalist, Glassmorphism, SaaS Light y Vintage Cartográfico).
SVG (Scalable Vector Graphics): Renderizado de gráficos vectoriales nativos para la visualización interactiva de nodos y aristas en estructuras complejas como grafos.
Lucide React: Librería de iconografía moderna utilizada para enriquecer la experiencia de usuario en los paneles de control y menús de navegación.

📚 Desafíos e Implementaciones (Challenges):

🎵 Challenge 03 — Listas Enlazadas (Singly & Doubly Linked Lists)
Descripción: Implementación de una Lista Simplemente Enlazada para un reproductor de música y una Lista Doblemente Enlazada para el historial de un navegador web.
Temática visual: Dark Mode Minimalista.

📚 Challenge 04 — Pila (Stack)
Descripción: Gestión LIFO (Last In, First Out) para el registro y manejo de una pila de libros con campos de título, ISBN, autor y editorial.
Temática visual: Dark Mode Dashboard.

🏧 Challenge 05 — Cola (Queue)
Descripción: Simulación FIFO (First In, First Out) para un sistema de turnos en un Cajero Automático Servibanca con montos en Pesos Colombianos (COP) y registro dinámico de horas de llegada.
Temática visual: Fintech Neo-Brutalist (Bancolombia/Davivienda style).

🌳 Challenge 08 — Árbol Binario de Búsqueda (BST)
Descripción: Construcción de un Árbol Binario de Búsqueda con inserción, verificación de existencia y recorridos en profundidad (Inorder, Preorder, Postorder) impresos en consola y pantalla.
Temática visual: Cyber-Visualizer con react-d3-tree.

🗂️ Challenge 09 — Árbol N-ario (N-ary Tree)
Descripción: Sistema de navegación lateral (Sidebar) multinivel e infinito basado en un Árbol N-ario, con renderizado dinámico de componentes y modal para agregar nuevos submenús.
Temática visual: SaaS Modern Elegant Light Theme.

🗺️ Challenge 10 — Grafos (Graph Theory)
Descripción: Representación de una red de amigos y ciudades de residencia mediante un Grafo no dirigido. Incluye visualizador SVG interactivo con simulación de fuerzas físicas, arrastre de nodos, pan & zoom y filtro de habitantes por ciudad.
Temática visual: Vintage Cartográfico / Atlas Antiguo.
